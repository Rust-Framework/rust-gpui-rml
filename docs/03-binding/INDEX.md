## 本章核心

RML 的数据绑定对标 WPF，提供四种绑定能力：

1. **单向绑定**：ViewModel → View，显示数据
2. **双向绑定**：ViewModel ↔ View，表单输入同步
3. **计算属性**：基于其他字段自动计算的派生值
4. **值转换器**：在绑定路径上进行类型或格式转换

所有绑定在编译期完成路径解析和类型检查，运行时零反射开销。
