## 本章核心

RML 的样式系统借鉴 CSS，但针对桌面应用做了优化：

- **CSS 子集**：支持常用的 CSS 属性、选择器、单位
- **Flexbox 布局**：主推 Flexbox，简化布局
- **主题系统**：通过 CSS 变量实现主题切换
- **样式复用**：全局样式、组件样式、工具类
- **响应式**：通过媒体查询适配不同窗口尺寸
