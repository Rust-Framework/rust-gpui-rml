## 本章核心

RML 语法可以浓缩为一句话：**HTML 标签 + HTML 属性 + `{ }` 插值 + 极简指令**。其中：

- HTML 标签和属性让你**零学习成本**读懂结构
- `{ }` 插值让你**声明式**地把 ViewModel 数据嵌入 UI
- 极简指令（`if`、`each`、`model` 等）让你**无前缀**地表达条件、循环、双向绑定
