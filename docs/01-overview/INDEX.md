## 关键概念速览

| 概念              | 一句话定义                                       |
| --------------- | ------------------------------------------- |
| **`.rml`**      | 独立的 UI 标记文件，使用 HTML 语法描述界面结构                |
| **`.rml.rs`**   | Code-Behind 文件，纯 Rust 业务逻辑                  |
| **ViewModel**   | 实现 `Model` trait 的 GPUI Entity，持有状态并响应命令     |
| **数据绑定**        | `.rml` 通过 `{ }` 插值消费 ViewModel 字段            |
| **命令**          | `#[command]` 标记的方法，可被 `.rml` 中的事件直接调用        |
| **编译期生成**       | `build.rs` 在编译期把 `.rml` 转为原生 GPUI 渲染代码       |
