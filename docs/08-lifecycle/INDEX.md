## 本章核心

RML 的生命周期管理是构建健壮应用的关键：

- **生命周期阶段**：创建 → 加载 → 更新 → 卸载
- **回调机制**：`#[on_loaded]`、`#[on_unloaded]`
- **异步任务**：在生命周期内启动和取消异步任务
- **资源管理**：文件句柄、网络连接、订阅的获取和释放
- **状态同步**：跨视图的状态同步和清理
