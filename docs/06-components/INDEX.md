## 本章核心

RML 的组件系统是构建大型应用的基础：

- **内置组件**：HTML 标签直接映射到 GPUI 元素和 gpui-component 组件
- **自定义组件**：用 `#[component]` 宏封装可复用的 UI 单元
- **插槽**：通过 `<slot>` 实现内容分发，提升组件灵活性
- **组件属性**：输入属性、事件属性、双向绑定
- **组件组合**：父子通信、兄弟通信、依赖注入
